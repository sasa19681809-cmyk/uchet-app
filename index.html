Учёт работ по заявкам

Раскрытые панели, свёрнутые виды и открытые списки запоминаются и восстанавливаются при следующем открытии,
а также передаются между устройствами вместе с резервной копией.

Данные: локальное устройство
Отчётный период

Первое нажатие на дату — начало периода, второе — конец.
Кнопка-триггер переключает отчёт между «всё время» и «выбранный период».

Данные
localStorage в этом режиме недоступен. Это не мешает работе: данные, копии и настройки GitHub хранятся во внутренней базе браузера (IndexedDB) и на GitHub.
GitHub (облачное хранение)

Настройки GitHub хранятся во внутренней базе браузера и работают даже при открытии файла с диска.
Токен не покидает ваш браузер. Используйте приватный репозиторий и fine-grained токен с правом Contents: Read and write только на этот репозиторий.

Локальные копии файлов

«Сохранить файл для переноса» и «Открыть файл с диска» — ручной обмен файлом через любое облако.
GitHub-синхронизация работает автоматически при включённой автосинхронизации, в том числе после возвращения интернета.
