Учёт работ по заявкам

Программа всегда открывается в свёрнутом виде — раскройте нужную панель стрелкой.
Облачное хранение: GitHub (приватный репозиторий, файл uchet-backup.json).
Любое изменение сохраняется локально и автоматически отправляется на GitHub.

Отчётный период
Данные
localStorage в этом режиме недоступен (часто бывает при открытии файла с диска). Это не мешает работе: данные, копии и настройки GitHub хранятся во внутренней базе браузера (IndexedDB) и на GitHub.
GitHub (облачное хранение)

Настройки GitHub хранятся во внутренней базе браузера и работают даже при открытии файла с диска.
Токен не покидает ваш браузер. Используйте приватный репозиторий и fine-grained токен с правом Contents: Read and write только на этот репозиторий.

Локальные копии файлов

«Сохранить файл для переноса» и «Открыть файл с диска» — ручной обмен файлом через любое облако.
GitHub-синхронизация работает автоматически при включённой автосинхронизации.

Виды работ

Кнопка «Изменить» открывает правку названия и времени; сохранённые работы с этим видом обновятся автоматически.
